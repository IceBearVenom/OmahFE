## Fitur yang Dikerjakan
- **Desain responsif:** Tampilan website menyesuaikan ukuran layar (HP, tablet, dan laptop/PC).
- **Validasi form:** Pengecekan input pada bagian *Contact Us* supaya kolom nama, email, dan pesan tidak kosong atau salah format sebelum dikirim.
- **FAQ bisa dibuka-tutup:** Pertanyaan di bagian FAQ bisa diklik untuk menampilkan atau menyembunyikan jawabannya.
- **Pop Up pada Sign-in dan Sign-up:** Saat tombol sign-in atau sign-up diklik pada navbar, sebuah pop up form untuk sign-in atau sign-up akan muncul.
